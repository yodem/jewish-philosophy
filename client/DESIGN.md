# שלום צדיק Design System

Hebrew RTL educational platform for Jewish religious philosophy.
Dark navy navbar, warm cream body (oklch 0.97 0.005 80), white card content areas.
NEVER use light/periwinkle blue backgrounds. Hero sections use bg-navbar (always dark navy).
Dark mode --primary stays dark navy — same as light mode. No bright blue surfaces.
Rubik font. Type scale: 12-14-16-18-20-24-30-36-48-60-72px.
Body text #222-#333. WCAG AA contrast 4.5:1.
Spacing: 4-8-12-16-24-32-48-64-96-128px.
7 nav items max. 8px border radius. Card-based layouts.
Content types: וידאו(blue) סדרה(purple) בלוג(green) שו״ת(orange) כתב(teal) מושג(pink)
